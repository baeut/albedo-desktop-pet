## 3D建模建议

- **低多边形数**：桌面宠物模式建议 8000-15000 三角面
- **骨骼数**：25-35根（头部/脊柱/手臂/手指/翼骨/发骨/裙骨）
- **纹理分辨率**：1024×1024 或 2048×2048
- **关键动画**：idle呼吸、眨眼、翼微动、害羞/惊吓/被拖拽
- **格式**：GLTF 2.0 (GLB binary)
